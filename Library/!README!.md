# How To Create Your Character

### Step One

- Set Your Initial Points to 175 Under `Settings > General Settings > Initial Points`
- Set your Default Tech Level to 3
- Navigate To Default Attributes under `Settings > Default Attributes`
- Select The Menu Dropdown To The Far Right
- Import The Default Attributes Provided With The Templates
- Create a New Character Sheet Under `File > New Character Sheet` Or Press `Ctrl + N`

### Step Two

- Fill Out Your Sheet's Description As You See Fit
